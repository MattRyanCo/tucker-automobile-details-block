A specialized block for documenting Tucker automobile details with proper nomenclature and descriptive information.

== Description ==

The Tucker Automobile Details block provides a structured way to document information about historic Tucker automobiles. It includes fields for:

* Tucker nomenclature (Tucker nnnn format where nnnn is the series number)
* Detailed vehicle description
* Production year
* Current status
* Location information
* Historical notes

This block is perfect for automotive historians, collectors, museums, and enthusiasts who want to maintain detailed records of these iconic American automobiles in a consistent format.

The block uses dynamic rendering to ensure that all information is properly displayed on the front end while providing an intuitive editing experience in the WordPress editor.

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/tucker-automobile-details` directory, or install the plugin through the WordPress plugins screen directly.
2. Activate the plugin through the 'Plugins' screen in WordPress
3. Add the "Tucker Automobile Details" block to any post or page
4. Enter the Tucker series number and other vehicle details

== Frequently Asked Questions ==

= What is the Tucker nomenclature format? =

Tucker automobiles are designated as "Tucker nnnn" where nnnn is a series of numbers identifying the specific vehicle. For example, "Tucker 1001" or "Tucker 1048".

= Can I add multiple Tucker automobile entries on one page? =

Yes! You can add as many Tucker Automobile Details blocks as needed to document multiple vehicles on a single page.

= Is this block compatible with the full site editor? =

Yes, this block works seamlessly with both the post editor and the full site editor.

== About Tucker Automobiles ==

The Tucker '48 (also known as the Tucker Torpedo) was an automobile conceived by Preston Tucker and briefly produced in Chicago in 1948. Only 51 vehicles were made before the company folded, making them highly sought-after collectibles today.
